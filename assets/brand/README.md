# VinylPilot — brand assets

Analog music. Digital sound.

Vector reconstruction of approved Variant 2. The monogram is redrawn, the wordmark uses outlined Inter Display Bold and the claim uses outlined Inter Regular; this is a close recreation, not an exact extraction of the AI concept. No font files are required or included. SVG and PNG light/dark logos have transparent backgrounds. “light” means for light backgrounds; “dark” means for dark backgrounds. Icon backgrounds are intentionally filled.

## Palette
- Charcoal `#251F23`
- Warm ivory `#F7F4F0`
- Bronze `#A77B4D`
- Muted text `#625B60` / `#C4BBC0`

## Usage
- GitHub README: `svg/logo-horizontal-light.svg` and `svg/logo-horizontal-dark.svg` via a picture element with prefers-color-scheme.
- Dashboard: horizontal logo, with or without claim.
- App icon: `svg/icon-rounded-dark.svg` or PNG sizes.
- GitHub social preview: `web/github-social.png` (1280 × 640).
- Website: `web/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `open-graph.png`.
- Original selected design: `reference/approved-variant-2.png`.

Use the SVGs as masters, keep proportions, and preserve clear space. No trademark clearance has been performed.
